# Weather and atmosphere

Add `WeatherDirector` to the same object as `GameRoot`. It finds the existing directional lights by the scene names `Golden hour sun` and `Cool forest bounce`, creates fallback lights when needed, and attaches `AtmospherePostEffect` to `Camera.main`. The scene uses the built-in renderer; no post-processing or URP package is required.

The initial state is Golden Hour. The automatic cycle changes every 75 seconds through golden hour, clear, overcast, rain, mist, golden hour, storm and clear. Lighting, fog, wind, wetness and particles blend over 12 seconds. Weather uses unscaled time so the forest continues moving behind menus. Storm lightning is a gentle single pulse every 11–19 seconds.

```csharp
WeatherDirector.Instance.SetAutoCycle(false);
WeatherDirector.Instance.SetWeather(WeatherKind.Rain); // smooth transition
WeatherDirector.Instance.SetWeather(WeatherKind.GoldenHour, true); // immediate
```

Public state includes `CurrentWeather`, `CurrentWeatherLabel`, `AutoCycle`, `Wetness` and `WindStrength`. All six kinds are `Clear`, `GoldenHour`, `Overcast`, `Rain`, `Mist` and `Storm`.

Apply `StickTD/GrassWind` to grass, ferns, flowers and tree foliage. It supports GPU instancing, Standard lighting, real-time shadows, moving cloud shade and rooted wind deformation. `_WindFlex` controls bending; `_RootHeight` defaults to zero. Apply `StickTD/WeatherSurface` to opaque ground, paths, soil and rocks to receive procedural cloud shade and rain wetness. Existing `_Color`, `_MainTex`, `_Glossiness` and `_Metallic` material properties are supported; `_WeatherResponse` controls the wet response.

Use `StickTD/Puddle` on the flat Blender puddle model, a little above the ground. Its alpha automatically follows weather wetness, with subtle sky tint and rain ripples. Keep puddle renderer shadows disabled.

Global shader values are `_WindDirection` (world XYZ), `_WindStrength`, `_WeatherWetness`, `_CloudShadow`, `_WeatherTime`, `_WeatherSkyColor` and `_ParticleGroundY`.

Optional mesh particles load the Blender FBX assets `Resources/Models/RainDrop`, `LeafParticle` and `Firefly` through `BlenderMeshCache.Get`, whose baked meshes preserve the authored Unity orientation of their rigged bind pose. The particle system uses the first cached part. No geometry or texture is generated by the weather code. Add `com.unity.modules.particlesystem` to the project package manifest. `Cloud` can remain available for scene decoration; atmospheric cloud shadow and drifting height fog are procedural shader effects.

Optional loop audio loads `Resources/Audio/weather_rain` and `weather_wind`. Their levels follow the smooth weather transition and respect `GameAudio.Muted`. Storm flashes trigger the existing audio player with `weather_thunder`.

Include these shaders in the player's Always Included Shaders list: `StickTD/GrassWind`, `StickTD/WeatherSurface`, `StickTD/WeatherParticle`, `StickTD/Puddle` and `Hidden/StickTD/Atmosphere`. The screen effect reconstructs world position from depth for low drifting mist, applies a restrained quarter-resolution bloom, a filmic curve, warm highlights, cool shadows and a subtle vignette. The UI remains outside the camera post-processing pass.
